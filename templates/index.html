Smart Grid Energy Consumption Forecasting & Analysis
no data API ·

ML-based smart grid energy consumption forecasting & analysis

Load genuine energy data by location, or upload your own meter dataset. The platform cleans and resamples the data, engineers time-series features, trains Linear Regression, Decision Tree and Random Forest on the same chronological split, compares them with MAE / RMSE / R², and forecasts future consumption.

Ingest → Clean & resample → Feature engineering → 3 models → Metrics → Forecast → Reports
Option A

Location-based analysis

Country-level electricity data from Our World in Data (annual, TWh). Real values only — if a series is too short for time-series ML, the platform says so instead of inventing data.

Option B

Dataset-based analysis

Upload CSV or Excel meter data (hourly, daily, monthly). Column detection is automatic, with manual override if the guess is wrong. Original file is preserved.

About this project

Final-year style academic platform: FastAPI + scikit-learn on the back end, Bootstrap + Chart.js on the front end, SQLite for live readings and metadata.
